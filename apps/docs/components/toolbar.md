# Toolbar 工具栏

工具栏用于组织一组操作按钮或工具，提供 start、center、end 三个分区插槽，便于在不同场景下统一布局。

## 何时使用

- 需要将多个操作按钮、搜索框、筛选器等控件按职能分组排列时。
- 顶部操作区、列表页头、详情页头部等场景需要明确的左 / 中 / 右分区布局时。
- 需要为操作区域提供语义化的 `role="toolbar"` 容器以增强可访问性时。

## 基础用法

:::demo 通过 `start`、`center`、`end` 三个插槽将工具栏内容分为左、中、右三区，配合按钮、输入框等组件组成完整操作栏。

## 分区插槽

:::demo 三个插槽可单独使用，也可组合使用。左侧通常放置主操作、面包屑；中间放置视图切换、搜索；右侧放置辅助操作或状态信息。

:::

## 与按钮组合

:::demo 工具栏常与按钮、按钮组配合使用。左侧放置主操作与高频操作，右侧放置危险操作或筛选。

:::

## 自定义内容

:::demo 工具栏的插槽接受任意内容，可放置面包屑、头像组、开关、统计数值、标签等业务组件。

:::

## API

### Toolbar Props

| 属性           | 说明                                | 类型   | 默认值 |
| -------------- | ----------------------------------- | ------ | ------ |
| ariaLabelledby | 工具栏标题元素的 id，用于无障碍关联 | string | -      |

### Toolbar Slots

| 插槽名 | 说明                   |
| ------ | ---------------------- |
| start  | 工具栏起始区域（左侧） |
| center | 工具栏居中区域         |
| end    | 工具栏末尾区域（右侧） |

### 无障碍

- 组件根节点会自动添加 `role="toolbar"` 属性。
- 通过 `ariaLabelledby` 关联标题元素，提升屏幕阅读器体验。
