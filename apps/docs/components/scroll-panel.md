# ScrollPanel 滚动面板

用于在固定区域内显示可滚动内容，并替换浏览器原生滚动条为自定义样式滚动条。

## 何时使用

- 内容超出容器高度或宽度，需要自定义滚动条样式时。
- 需要在有限空间内展示大量内容时。
- 希望滚动条在视觉上与整体设计系统保持一致时。

## API

通过设置 `ScrollPanel` 的属性来控制滚动行为。

### Props

| 属性 | 说明 | 类型 | 默认值 | 版本 |
| --- | --- | --- | --- | --- |
| step | 使用键盘方向键（ArrowUp / ArrowDown / ArrowLeft / ArrowRight）滚动时，每次移动的像素距离 | number | `5` |  |

### 事件

`ScrollPanel` 组件当前未定义额外的自定义事件。组件内部会响应容器原生滚动事件并更新自定义滚动条位置。

### Slots

| 名称    | 说明           | 参数 |
| ------- | -------------- | ---- |
| default | 需要滚动的内容 | -    |

### 方法

#### ScrollPanel

| 名称             | 描述                               | 参数                      | 版本 |
| ---------------- | ---------------------------------- | ------------------------- | ---- |
| refresh()        | 手动重新计算并刷新滚动条尺寸与位置 | -                         |      |
| scrollTop(value) | 滚动内容到指定纵向位置             | `(value: number) => void` |      |

## 使用建议

### ScrollPanel vs 原生滚动

| 场景 | 推荐方案 | 说明 |
| --- | --- | --- |
| 只需要简单滚动，且不关注滚动条样式 | 原生滚动 + CSS `overflow` | 原生滚动在移动端和辅助设备上表现更好 |
| 需要统一设计系统滚动条样式 | `ScrollPanel` | 可自定义滚动条外观，保持跨浏览器一致性 |
| 内容高度/宽度动态变化 | `ScrollPanel` | 可调用 `refresh()` 重新计算滚动条状态 |
| 需要完整的无障碍访问支持 | 原生滚动 | 自定义滚动条需要额外处理 ARIA 属性与键盘交互 |

### 注意事项

- `ScrollPanel` 会隐藏原生滚动条，请确保容器具有明确的 `width` 或 `height` 约束，否则无法触发滚动。
- 当容器内容动态变化时，可能需要调用组件实例的 `refresh()` 方法重新计算滚动条。
- 键盘方向键滚动仅在滚动条获得焦点时生效，可通过 Tab 键将焦点移动到滚动条上。
