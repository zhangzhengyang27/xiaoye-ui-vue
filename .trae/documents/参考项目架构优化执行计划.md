# 参考项目架构优化执行计划

## Summary

将当前扁平单包的 ant-design-vue-main（包名 `xiaoye-ui@4.2.6`）重构为对齐参考项目 `xiaoye-ui-vue` 的 pnpm monorepo 架构。涵盖 9 个可参考点：monorepo 垂直拆分、文档站迁移 Nuxt、入口与 exports 自动生成、package.json exports 双态设计、pnpm catalog 版本治理、共享层多级抽象、构建链迁移 Vite 库模式（ESM-only）、测试迁移 Vitest、AGENTS.md 工程化文档。

## 已确认的关键决策

| 决策项 | 选择 | 说明 |
|---|---|---|
| monorepo 拆分粒度 | 完整对齐参考项目 | 拆 8+ 个包：xiaoye-ui / core / utils / icons / metadata / auto-import-resolver / vite-plugin / nuxt-module / mcp |
| 构建产物策略 | ESM-only | 仅产 ESM（`dist/`），废弃 CJS/UMD。影响：旧 CJS 项目无法 require，CDN 用户改用 esm.sh |
| 文档站 | 迁移到 Nuxt | 从 `site/`(Vite+Vue) 迁移到 `apps/showcase/`(Nuxt)，获 SSR/SEO |

## Current State Analysis

### 当前项目结构
- 扁平单包，`components/` 一个大目录承载 70+ 业务组件、27 个 vc-* 底层组件、`_util/` 共享工具、`theme/` 主题、`style/` 样式
- `xy-tools/` 松散脚本集合（无 package.json，仅被 npm scripts 调用）
- `site/` 文档站（Vite 3 + Vue3 + less）
- 构建：gulp + tsc + babel + webpack（产 ESM/CJS/UMD 三套）
- 测试：jest + ts-jest + vue3-jest

### 已识别的问题
1. `package.json` 缺 `exports` 字段，按需加载靠 `es/xxx` 隐式结构
2. `components/components.ts`（269 行）与 `typings/global.d.ts`（273 行）手工维护，已双向漂移（`AStyleProvider` 多余、`AApp` 缺失）
3. `.husky/`（v6+）与 `.huskyrc`（v4）双重配置并存
4. `_util/` 混杂可渲染组件、cssinjs 引擎、纯工具函数（100+ 文件）
5. 无 `_shared/` 跨组件样式片段目录
6. 无 AGENTS.md 工程化文档
7. `tsconfig.json` 未开 strict
8. 入口文件 `index-style-only.js` 依赖 webpack `require.context`
9. `vc-slick/` 全是 `.js/.jsx`，其他 vc-* 已 `.ts/.tsx`
10. 废弃依赖：`@babel/polyfill`、`babel-eslint`、`@vue/cli-plugin-eslint`

## Proposed Changes

按 9 个阶段执行，每阶段完成后验证再进入下一阶段。

---

### 阶段 1：monorepo 基础设施搭建

**目标**：建立 pnpm workspace 骨架，创建包目录结构。

**具体改动**：

1. **创建 `pnpm-workspace.yaml`**（根目录）
   ```yaml
   packages:
     - 'packages/*'
     - 'apps/*'
   catalogs:
     app:
       vue: 3.4.0
       vite: 7.3.2
       typescript: 5.4.0
       # ...其他跨包共享版本
   ```

2. **创建目录结构**：
   ```
   packages/
   ├── xiaoye-ui/          # 主组件库（从 components/ 迁入）
   ├── core/               # 运行时插件（BaseComponent、XiaoyeUI config）
   ├── utils/              # 纯工具函数（从 _util/ 纯工具部分抽出）
   ├── icons/              # 图标包（从 @ant-design/icons-vue 解耦）
   ├── metadata/           # 组件元数据（供自动导入）
   ├── auto-import-resolver/  # unplugin-vue-components resolver
   ├── vite-plugin/       # Vite 自动导入插件
   ├── nuxt-module/       # Nuxt 3 集成模块
   └── mcp/               # MCP server（AI 集成）
   apps/
   ├── showcase/          # 主文档站（Nuxt，阶段 5 迁入）
   └── volt/              # 演示站（可选，暂留空）
   ```

3. **迁移 `components/` → `packages/xiaoye-ui/src/`**
   - 整体移动 `components/*` → `packages/xiaoye-ui/src/*`
   - 保留 `_util/`、`vc-*`、`theme/`、`style/`、`config-provider/`、`locale/`、`locale-provider/` 在主包内
   - 纯工具函数（`classNames.ts`、`omit.ts`、`raf.ts`、`getScroll.ts`、`isNumeric.ts`、`KeyCode.ts`、`warning.ts` 等）迁移到 `packages/utils/src/`

4. **迁移 `xy-tools/` → `packages/build-tools/`**
   - 添加 `package.json`，name: `@xiaoye-ui/build-tools`
   - 保持 `gulpfile.js`、`getWebpackConfig.js`、`getBabelCommonConfig.js`、`getTSCommonConfig.js`、`cli/`、`generator-types/` 结构

5. **根 `package.json` 调整**：
   - `name`: `@xiaoye-ui/monorepo`
   - `private`: true
   - `packageManager`: `pnpm@9.6.0`
   - `engines.node`: `>=18.0.0`
   - `scripts` 改为 `pnpm --filter` 编排模式
   - 添加 `workspaces` 或依赖 `pnpm-workspace.yaml`

**验证**：`pnpm install` 成功，`pnpm --filter xiaoye-ui` 能定位到主包。
