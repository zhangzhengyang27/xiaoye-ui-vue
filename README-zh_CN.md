# Xiaoye UI

企业级 UI 设计语言和 Vue 实现。

[English](./README.md)

## 特性

- 企业级中后台产品的交互语言和视觉风格。
- 开箱即用的高质量 Vue 组件。
- 支持服务端渲染。

## 支持环境

- Vue >= 3.2.0
- Node >= 12.22.0
- 现代浏览器
- 支持服务端渲染
- [Electron](https://electronjs.org/)

## 安装

```bash
npm install xiaoye-ui
```

或

```bash
yarn add xiaoye-ui
```

## 使用示例

```vue
<template>
  <Button type="primary">Hello</Button>
</template>

<script setup>
import { Button } from 'xiaoye-ui';
</script>
```
