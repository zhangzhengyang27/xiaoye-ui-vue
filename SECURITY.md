## Reporting a Vulnerability

If you discover a security vulnerability, please report it by opening an issue at https://github.com/xiaoye-ui/xiaoye-ui/issues. You can expect an update on a reported vulnerability within a reasonable timeframe, and we will let you know whether the vulnerability is accepted or declined.
